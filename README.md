# Archie Maze

An isometric hedge maze. Archie stays in the middle of the screen and the maze scrolls around him. Find the stone gate.

## Play

```bash
pip install -r requirements.txt
python3 game.py
```

Arrow keys or WASD to walk. Down or S walks down-left, Right or D walks down-right, Up or W walks up-right, and Left or A walks up-left. Esc quits. After the exit, Enter, R, or Space starts a new maze.

```bash
python3 game.py --seed 1
```
