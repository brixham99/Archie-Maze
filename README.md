# Archie Maze

An isometric hedge maze. Archie stays in the middle of the screen and the maze turns around him. Find the stone gate.

## Play

```bash
pip install -r requirements.txt
python3 game.py
```

Left or A turns the view left. Right or D turns it right. Up or W steps forward, and Down or S steps back. Forward always points up the screen. Esc quits. After the exit, Enter, R, or Space starts a new maze.

```bash
python3 game.py --seed 1
```
